# Module `landing` — Responsable : Charles

Page d'accueil publique (`src/app/page.tsx`). Composants statiques, sans JavaScript client, sans appel serveur.

Règles de contenu : aucun slogan officiel, aucun témoignage, aucun nombre d'utilisateurs, aucun tarif ; les fonctions
non livrées portent « En construction » ou « Bientôt » ; les aperçus sont illustratifs (données inventées,
`MockBadge`). Pas de pages légales (mentions, confidentialité) : à ajouter avant l'ouverture au public.
